# Product Vision

Where BettyOS is going. This is the destination—not a description of the system today. For the current shape of the project, see [ARCHITECTURE.md](ARCHITECTURE.md).

## Creative Operations System

BettyOS aims to be a reusable **Creative Operations System**: a local-first tool for creative planning, production, review, and distribution. It is not a single-brand script and not a computer operating system.

## Generic engine, brand-specific data

The product engine should work for any brand. Brand voice, constraints, and assets live as brand profiles under `brands/`. **Oh Betty Jaletti** is the first profile—proof that the engine works—not the identity of BettyOS.

## Future capabilities

These are goals for later sprints, not current architecture:

- **Production Sessions** — structured units of work: plan → produce → review.
- **Brand Profiles** — first-class inputs for voice, constraints, and assets.
- **Platform-specific workflows** — guidance and production tailored to channels (for example, Pinterest), added as real needs appear.
- **Model-agnostic AI** — use AI where it helps production, without locking product logic to a single provider. Swap models without rewriting the product.

## How to read this document

Vision describes intent. The [Roadmap](ROADMAP.md) sequences capabilities. [Architecture](ARCHITECTURE.md) stays present-tense and lean until those capabilities are built.
