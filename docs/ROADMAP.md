# Roadmap

Capability milestones for BettyOS. Outcomes describe what users can do—not how we implement it.

**Current:** v1.0.0-beta — MVP Hardening

## Shipped in v1.0.0-beta

- Plan production sessions with Brand Brain context
- Ingest and index local media into an asset library
- Repurpose indexed assets into content packages
- Render supported drafts (`page-turn-loop`, `ritual-reel`) singly or via `create all`
- Review packages/renders with the Review Brain (critique only)
- Approve campaign assets in the terminal

## Next

### Brand QA

Check outputs against the active Brand Brain so production stays on-brand before distribution.

### Additional platform workflows

Add platform-specific guidance (for example Pinterest) as real production needs appear—not before.

### Additional render templates

Add new templates only when a recurring campaign piece needs them. Do not invent formats in advance.
